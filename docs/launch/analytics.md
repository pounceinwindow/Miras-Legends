# Аналитика первого маршрута

## Главная воронка

`ролик → открытие ссылки → запуск приложения → открытие карты → подтверждение точки → начало боя → победа → второй маршрут → публикация результата`

## События

| Событие | Когда отправляется | Параметры |
| --- | --- | --- |
| `app_open` | Первый экран открыт | platform, app_version, source |
| `starter_received` | Игрок получил Су анасы | character_id |
| `map_opened` | Открыта карта | collection_size |
| `location_selected` | Нажата точка | location_id, character_id |
| `location_verified` | Успешны GPS и AR/QR | location_id, method |
| `story_opened` | Открыта история | character_id |
| `battle_started` | Начался бой | boss_id, squad_size |
| `battle_finished` | Бой завершён | boss_id, result, duration_sec, hp_left |
| `character_joined` | Босс добавлен в коллекцию | character_id |
| `share_opened` | Открыта карточка результата | character_id |
| `share_completed` | Сработал системный Share | channel, character_id |
| `route_completed` | Побеждены два босса пилота | duration_min |

## Основные показатели

- Activation: доля открывших приложение, которые начали первый бой.
- First boss completion: доля начавших, которые победили первого босса.
- Route completion: доля игроков, победивших обоих боссов.
- D1 и D7 return: возврат на следующий день и в течение недели.
- Share rate: доля победителей, отправивших карточку.
- Location conversion: доля выбравших точку, которые подтвердили присутствие.

## Решения по данным

- Мало открытий после ролика: менять первые две секунды и призыв.
- Открывают игру, но не карту: упрощать онбординг.
- Выбирают точку, но не доходят: уменьшать расстояние или усиливать награду.
- Начинают бой, но часто проигрывают: менять подсказки и баланс.
- Проходят маршрут, но не делятся: менять карточку результата и момент предложения.
