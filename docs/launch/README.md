# Запуск «Мирас»

Эта папка собирает продуктовый, контентный и магазинный запуск в один рабочий план. Цель первого цикла — проверить, готовы ли люди из Казани открыть игру после короткого ролика, пройти реальную точку и вернуться за следующим хранителем.

## Что выпускаем

- Бесплатная мобильная игра для прогулок по Казани.
- Стартовый хранитель Су анасы выдаётся сразу.
- Первый маршрут содержит две обязательные встречи: Казанский кремль и Сююмбике.
- Третья точка с Шурале открывает следующий маршрут.
- На точке игрок читает короткую историю, видит татарскую реплику с русским переводом, побеждает босса и добавляет его в коллекцию.
- После победы игрок получает карточку, которой можно поделиться.

## Критерий успешного пилота

Пилот считается перспективным, если за первые семь дней:

- не менее 50 человек открыли маршрут;
- не менее 40% начали первый бой;
- не менее 25% победили первого босса;
- не менее 20% вернулись за второй точкой;
- не менее 10 человек поделились результатом или пригласили друга.

## Порядок запуска

### Неделя 1. Продукт

1. Проверить старт без регистрации и получение Су анасы.
2. Проверить карту, разрешения камеры и геолокации на Android и iPhone.
3. Подготовить две физические AR-метки и QR-дубли.
4. Подключить события из `analytics.md`.
5. Провести маршрут всей командой на реальных устройствах.

### Неделя 2. Контент и закрытый тест

1. Снять первые восемь роликов из `shorts-plan.md`.
2. Набрать 12 постоянных Android-тестировщиков и ещё 8 запасных.
3. Запустить закрытый тест Google Play минимум на 14 дней.
4. Создать общий чат тестировщиков и собирать ответы после каждой точки.
5. Выпускать один короткий ролик ежедневно во все площадки.

### Неделя 3. Исправления

1. Исправить блокирующие ошибки камеры, GPS и входа.
2. Сократить места, где игрок не понимает следующий шаг.
3. Обновить баланс по фактическим результатам боёв.
4. Подготовить магазинные скриншоты и тексты из `store-listing.md`.

### Неделя 4. Публичный запуск

1. Запросить production-доступ в Google Play.
2. Опубликовать публичный маршрут и ролик с точной датой запуска.
3. Разместить QR-коды у партнёров и на разрешённых площадках.
4. Начать переговоры по одному партнёрскому боссу.
5. Решение по App Store принимать по метрикам первого маршрута.

## Команды мобильной сборки

```bash
npm ci
npm run mobile:sync
npm run mobile:android
npm run mobile:ios
```

`mobile:sync` собирает React-приложение и переносит результат в Android и iOS проекты. Команды `mobile:android` и `mobile:ios` открывают нативные проекты для подписи и публикации.
