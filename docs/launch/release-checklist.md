# Проверка релиза

## Общая

- [ ] В репозитории нет `service_role`, паролей и приватных ключей.
- [ ] Supabase RLS включён для пользовательских таблиц.
- [ ] Все ссылки используют HTTPS.
- [ ] Приложение работает без обязательного ручного входа.
- [ ] Политика конфиденциальности опубликована по постоянному URL.
- [ ] Страница поддержки опубликована по постоянному URL.
- [ ] Источники историй открываются и соответствуют текстам.
- [ ] AR-метки имеют QR-дубль.

## Android

- [ ] Установлены Android Studio, актуальный SDK и JDK 21.
- [ ] Если используется JDK из Android Studio, перед консольной сборкой задано: `export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"`.
- [ ] `npm run mobile:sync` завершён без ошибок.
- [ ] Локальная debug-сборка проходит командой `cd android && ./gradlew assembleDebug`.
- [ ] Проверены камера, GPS и системная кнопка «Назад».
- [ ] Создан закрытый тест Google Play.
- [ ] 12 тестировщиков подключены непрерывно на 14 дней.
- [ ] Создан release keystore и сохранён вне Git.
- [ ] Собран подписанный Android App Bundle `.aab`.
- [ ] Заполнены Data safety, Content rating и App access.
- [ ] Загружены иконка, feature graphic и скриншоты.

## iOS

- [ ] Есть Apple Developer account и App Store Connect record.
- [ ] Bundle ID совпадает с `ru.miras.legends` или осознанно заменён везде.
- [ ] Тексты разрешений камеры и геолокации проверены.
- [ ] Приложение проверено на реальном iPhone.
- [ ] Интерфейс даёт полноценную игровую ценность и не выглядит как сайт в оболочке.
- [ ] Заполнены App Privacy и возрастной рейтинг.
- [ ] Создана TestFlight-группа.
- [ ] В Review Notes описан маршрут проверки без поездки в Казань.

## Перед нажатием Publish

- [ ] Версия и номер сборки увеличены.
- [ ] Production Supabase применил все миграции.
- [ ] Команда прошла маршрут с чистого аккаунта.
- [ ] Ссылка поддержки принимает сообщения.
- [ ] Есть план быстрого отката или отключения проблемной точки.
